# Special Abilities Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Sky Team's six Special Ability cards (Working Together, Synchronisation, Mastery, Control, Anticipation, Adaptation), chosen by the host in the lobby and fully enforced by the server.

**Architecture:** Abilities are game-setup data like modules: the host picks them in the lobby, `scenarioForSetup` copies them onto the `Scenario`, and the pure reducer (`packages/shared/src/game/reducer.ts`) enforces them via `hasAbility()`. Passive abilities hook existing resolve steps; active abilities are new commands. Anything random (Anticipation's reroll, Synchronisation's Traffic die) is generated by the server and threaded into the reducer as command data, exactly like dice rolls today. Each ability is one task, one rules-test section and one UI piece.

**Tech Stack:** TypeScript monorepo (npm workspaces): `@skyteam/shared` (zod protocol + pure reducer), `@skyteam/server` (Express + Socket.IO + Redis), `@skyteam/client` (React + Vite + Zustand). Tests are plain `.mjs` scripts run with `tsx`.

**Spec:** the "Rules (spec)" section below, taken from the official Dized rules pages (sources at the end). There is no separate spec document.

## Rules (spec)

| Ability | Effect | Frequency | Kind |
|---|---|---|---|
| **Working Together** | The active player puts one of their unplaced dice on the card; the other player must then put one of theirs on it too (if they have one). The two dice swap values and both go back to their owners' hands, unplaced. | Once per round | Active, 2-step handshake |
| **Synchronisation** | As soon as at least one die is on Landing Gear and one on Flaps (this round), roll the Traffic die (faces 2,3,3,4,4,5). The **Co-Pilot** places it on any empty Control Panel space, regardless of colour, and it acts as a normal die. Extra action — it doesn't use up a turn. | Once per round (the condition becomes true once) | Triggered, server entropy |
| **Mastery** | Two Engine dice of the same value → immediately gain a Reroll token, only if one is available (i.e. a used token back in the supply). | Every time it triggers | Passive |
| **Control** | Two Axis dice of the same value → immediately gain a Coffee token (Coffee is capped at 3). | Every time it triggers | Passive |
| **Anticipation** | Each round, before placing their first die, the First Player may reroll one of their dice. | Once per round, First Player only | Active, server entropy |
| **Adaptation** | Each player may, once per game, turn one of their unplaced dice to its opposite face (1↔6, 2↔5, 3↔4). | Once per game per player | Active |

Scenarios say how many cards may be chosen (0, 1 or 2). YUL has no Flight Log number in the code yet, so the host may choose up to `scenario.maxAbilities ?? 2`.

## Open questions (resolve with the user before the task that needs them)

1. **YUL's ability count** (Task 1): default 2? The physical scenario card shows the number in a star.
2. **Adaptation off-turn** (Task 3): the card says "at any point". This plan allows it on either player's turn during placement, but never while a Reroll/Swap/Intern/Traffic action is pending.
3. **Traffic die on Concentration / Intern board** (Task 6): "any empty space on the Control Panel" — this plan allows Concentration (it's on the panel) but not the Intern board (separate module board).
4. **Mastery availability** (Task 2): modelled as "a spent Reroll token is back in the supply" (`rerollSpent > 0`).

## Review Focus

- **A held Traffic die while the Pilot's turn is in progress**: Synchronisation can trigger on the Pilot's placement but the Co-Pilot places the die; after it, the turn must pass to the Co-Pilot (the triggering player's opponent), not the Pilot. Test in Task 6.
- **Synchronisation triggered by the round's 8th die**: the round must wait for the Traffic die to be placed, then end (like the Intern's 8th-die case). Test in Task 6.
- **Traffic die with no empty space**: must not deadlock — it is discarded with a log line. Test in Task 6.
- **Working Together when the other player has no dice left**: initiation must be refused, never leave a dangling `pendingSwap`. Test in Task 5.
- **Old rooms in Redis without `abilities`**: `getRoom` must default them (like `setup` for pre-setup rooms) and old games must not crash `hasAbility`. Test in Task 1 (unit) — `scenario.abilities` undefined ⇒ `hasAbility` false.

```ts
  .object({
    scenarioId: z.enum(SCENARIO_IDS),
    modules: z
      .array(z.enum(MODULE_IDS))
      .max(MODULE_IDS.length)
      .refine((m) => new Set(m).size === m.length, "Duplicate module.")
      .refine((m) => m.every((id) => IMPLEMENTED_MODULES.includes(id)), "That module is not available yet.")
      .refine(
        (m) => EXCLUSIVE_MODULE_GROUPS.every((group) => group.filter((id) => m.includes(id)).length <= 1),
        "Those modules can't be played together.",
      ),
    abilities: z
      .array(z.enum(ABILITY_IDS))
      .refine((a) => new Set(a).size === a.length, "Duplicate ability.")
      .default([]),

    const max = SCENARIOS[setup.scenarioId].maxAbilities ?? DEFAULT_MAX_ABILITIES;
    if (setup.abilities.length > max) {
      ctx.addIssue({ code: z.ZodIssueCode.custom, message: `This scenario allows at most ${max} Special Abilities.` });

  }) satisfies z.ZodType<GameSetup, z.ZodTypeDef, unknown>;
```

```ts
/** Adaptation: once per game, a player turns one unplaced die to its opposite face. */
function handleAdapt(s: GameState, cmd: { dieId: number }, byPlayerId: PlayerId): ReduceResult {
  if (s.phase !== "placement") throw new GameRuleError("You can only adapt a die during placement.");
  if (!hasAbility(s, "adaptation")) throw new GameRuleError("Adaptation is not in play.");
  if (s.pendingReroll !== null || s.internHeld) throw new GameRuleError("Finish the current action first.");
  const crew = requireCrew(s, byPlayerId);
  if (s.adaptationUsed[crew]) throw new GameRuleError("You have already used Adaptation.");
  const die = s.dice[crew].find((d) => d.id === cmd.dieId);
  if (!die || die.value === undefined || die.placed) throw new GameRuleError("Pick one of your unplaced dice.");
  die.value = (7 - die.value) as DieValue;
  s.adaptationUsed[crew] = true;
  s.log.push(`${crewLabel(crew)} used Adaptation.`);
  return { state: s, description: "Die turned over." };
}
```

```ts
/** Anticipation: each round, before their first die, the First Player may reroll one die. */
function handleAnticipate(s: GameState, cmd: { dieId: number; value: DieValue }, byPlayerId: PlayerId): ReduceResult {
  if (s.phase !== "placement") throw new GameRuleError("Not during placement.");
  if (!hasAbility(s, "anticipation")) throw new GameRuleError("Anticipation is not in play.");
  const crew = requireCrew(s, byPlayerId);
  if (crew !== firstPlayerForRound(s.round)) throw new GameRuleError("Only the First Player can anticipate.");
  if (s.anticipated) throw new GameRuleError("Anticipation is used this round.");
  if (s.dice[crew].some((d) => d.placed)) throw new GameRuleError("Only before your first die.");
  if (s.pendingReroll !== null || s.internHeld) throw new GameRuleError("Finish the current action first.");
  const die = s.dice[crew].find((d) => d.id === cmd.dieId);
  if (!die || die.placed) throw new GameRuleError("No such die.");
  die.value = cmd.value;
  s.anticipated = true;
  s.log.push(`${crewLabel(crew)} used Anticipation (rerolled one die).`);
  return { state: s, description: "Die rerolled." };
}
```

```ts
/**
 * Working Together (once per round): the active player offers one unplaced die;
 * the other player must answer with one of theirs; the values swap. Two-step
 * handshake like the joint reroll — `pendingSwap` locks everything else.
 */
function handleSwap(s: GameState, cmd: { dieId: number }, byPlayerId: PlayerId): ReduceResult {
  if (s.phase !== "placement") throw new GameRuleError("Not during placement.");
  if (!hasAbility(s, "workingTogether")) throw new GameRuleError("Working Together is not in play.");
  const crew = requireCrew(s, byPlayerId);
  const die = s.dice[crew].find((d) => d.id === cmd.dieId);
  if (!die || die.value === undefined || die.placed) throw new GameRuleError("Pick one of your unplaced dice.");

  if (s.pendingSwap === null) {
    if (s.turn !== crew) throw new GameRuleError("Only the active player can start Working Together.");
    if (s.swappedThisRound) throw new GameRuleError("Working Together is used this round.");
    if (s.pendingReroll !== null || s.internHeld) throw new GameRuleError("Finish the current action first.");
    if (s.dice[other(crew)].every((d) => d.placed)) throw new GameRuleError("The other player has no dice to swap.");
    s.pendingSwap = { from: crew, dieId: die.id };
    s.swappedThisRound = true;
    s.log.push(`${crewLabel(crew)} asks to work together.`);
    return { state: s, description: "Swap offered." };
  }
  if (crew === s.pendingSwap.from) throw new GameRuleError("Waiting for the other player.");
  const offered = s.dice[s.pendingSwap.from].find((d) => d.id === s.pendingSwap!.dieId)!;
  [offered.value, die.value] = [die.value, offered.value];
  s.pendingSwap = null;
  s.log.push("Working Together: two dice swapped values.");
  return { state: s, description: "Dice swapped." };
}
```

```ts
/** Which crew a space belongs to, for a die placed "regardless of colour". */
function spaceOwner(target: PlacementTarget, placer: Crew): Crew {
  switch (target.kind) {
    case "axis": case "engine": case "radio": return target.side ?? placer;
    case "landingGear": case "brakes": return "pilot";
    case "flaps": return "copilot";
    case "iceBrakes": return target.space === "top" ? "pilot" : placer;
    default: return placer; // shared spaces: Concentration, Kerosene
  }

/** Synchronisation trigger, checked after every placement (die, token, Traffic die). */
function checkSynchronisation(s: GameState, turnOf: Crew): void {
  if (!hasAbility(s, "synchronisation") || s.syncDone) return;
  if (s.gearSlots.some((v) => v !== null) && s.flapSlots.some((v) => v !== null)) {
    s.syncDone = true;
    s.trafficPending = true;
    s.trafficTurnOf = turnOf; // whose turn the extra action belongs to
  }
}

function handleRollTraffic(s: GameState, cmd: { value: DieValue }): ReduceResult {
  if (!s.trafficPending) throw new GameRuleError("No Traffic die to roll.");
  s.trafficPending = false;
  if (!dieHasSpace(s, "copilot", cmd.value, { anyColour: true })) {
    s.log.push(`Synchronisation: the Traffic die (${cmd.value}) has nowhere to go.`);
    return finishTurn(s, s.trafficTurnOf!);
  }
  s.trafficHeld = { value: cmd.value, forTurnOf: s.trafficTurnOf! };
  s.log.push(`Synchronisation: Traffic die rolled ${cmd.value} — the Co-Pilot places it.`);
  return { state: s, description: "Traffic die rolled." };
}

function handlePlaceTraffic(s: GameState, cmd: { target: PlacementTarget }, byPlayerId: PlayerId): ReduceResult {
  const crew = requireCrew(s, byPlayerId);
  if (!s.trafficHeld) throw new GameRuleError("There is no Traffic die to place.");
  if (crew !== "copilot") throw new GameRuleError("Placing the Traffic die is the Co-Pilot's duty.");
  if (cmd.target.kind === "intern") throw new GameRuleError("Not on the Intern board.");
  const owner = spaceOwner(cmd.target, crew);
  applyPlacement(s, owner, s.trafficHeld.value, cmd.target);
  s.trafficPlaced.push(placementKey(owner, cmd.target));
  const turnOf = s.trafficHeld.forTurnOf;
  s.trafficHeld = null;
  if (s.outcome) { s.phase = "lost"; return { state: s, description: lossText(s) }; }
  return finishTurn(s, turnOf);
}

/** End a turn: end the round if every die is down, else pass to the other crew. */
function finishTurn(s: GameState, crew: Crew): ReduceResult {
  if (s.placedThisRound >= DICE_PER_PLAYER * 2) { endOfRound(s); return { state: s, description: endText(s) }; }
  s.turn = other(crew);
  return { state: s, description: "Turn passed." };
}
```
